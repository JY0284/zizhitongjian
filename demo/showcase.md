# 当前版本截图与功能核对

截图日期：2026-10-19。全部来自真实浏览器，使用仓库 `visualization/snapshot/` 中的前五卷公开快照；未修改图片中的数据或界面。默认桌面视口为 1280 × 720，整页图高度随内容变化；手机图在 390 × 844 的响应式测试中拍摄。浏览器原生输出为 JPEG。

本次替换原有 9 张 PNG 演示图，并新增人物聚焦、势力人物和移动阅读 3 张图片。旧亮点保留，新增能力与验证路径如下。

## 原有能力与新版增量

| 原有能力 | 新版入口与增量 | 已核对的行为 |
| --- | --- | --- |
| 时间轴全局概览、密集事件聚类 | 时间全景按视窗宽度聚合，下方仍可逐年阅读 | 全程 683 件有年份事件；前 403–399 年聚合柱展开为 5 个年份、20 件事 |
| 时间轴缩放、平移 | 放大/缩小、拖动、更早/更晚、查看全程；另有全程位置条 | 缩放与平移按钮改变视窗，复位恢复全程；边界与单年情况有单元测试 |
| 事件搜索与详情 | 搜索联动概览、支持别名，待考年份单列 | 搜“商鞅”得到 36 件事，其中 24 件有年份、12 件待考；卡片可打开详情 |
| 力导向人物关系图 | 默认重点 50 人，可切换全部 500 人；节点大小、势力颜色、拖拽和缩放保留 | 全量/重点切换、画布适配和关系连接可用 |
| 图谱密度筛选 | 最低提及次数滑块与重置，叠加势力筛选 | 阈值 21 时显示 2 人；重置回 50 人，关系不会悬空 |
| 人物与连线详情 | 点击或 Enter/空格打开；双向互动与关联事件保留 | 司马错—秦惠王打开两条互动记录；Escape 关闭详情 |
| 人物检索 | 姓名/别名搜索后聚焦直接关系；新增文字关系列表 | 司马错显示 4 人、6 条关系，包含直接邻居之间的连线 |
| 势力统计 | 点击柱条看成员，再读人物详情；数量含义明确 | 保留势力选择与成员浏览，不把人物数表述为国力 |
| 地点列表、古今对照与详情 | 搜索地点、描述或今地名；地图入口独立可点 | 搜“河北”显示 3 个地点；地点与事件详情互通 |
| 地点关联人物跳转 | 自动扩展/切换到人物所在卷，国家与组织单列 | 卷 1 的蜀 → 卷 3 陈庄 → 浏览器返回卷 1 蜀详情 |
| 交互地图 | 地点选择、缩放、查看全部位置、参考点开关，URL 保存定位 | 邯郸定位与说明可见；25 个现代参考位置与 0 个已核验古址明确区分 |
| 卷/年筛选与返回 | 输入草稿经校验再应用；保留联动、预设及 URL 状态 | 整数、上下界、反向范围和年份待考排除规则有回归测试 |
| 移动端与键盘操作 | 五个视图保留，筛选/概览可折叠、年份横向选取、详情焦点恢复 | 320、390、1024 像素宽度下逐个打开五个视图，无页面横向溢出 |
| 文白对照阅读与 Agent 查询 | 294 卷阅读入口、全文检索 Skill、原文定位继续保留 | 发布构建核验 294 个章节，公开快照与查询入口不变 |

人物/事件轨迹一直是待完成项。当前没有已核验古址，不把现代参考点拼接成古代行军路线；参见[任务地图](../docs/architecture/task_map.md)。模型抽取与实体融合仍需人工审校，截图不能替代史料核验。
